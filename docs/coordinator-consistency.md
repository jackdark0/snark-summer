# Coordinator Consistency Tracker

This tracker summarizes repeated coordinator-side patterns across accepted
examples. It is not a complete allegation ledger. It only cites examples already
in `docs/tactic-example-bank.md`; retired duplicates are not counted as primary
evidence. For internal position conflicts, see
`docs/coordinator-contradictions.md`.

## Method

- Use canonical names from `docs/actor-aliases.md` in authored prose.
- Preserve source wording inside quotes, titles, URLs, and transcript filenames.
- Treat YouTube auto-caption examples as provisional until audio verification.
- Track consistency by date, tactic, and repeated argumentative function, not by
  isolated wording.
